# Failover 줄별 해석

> **대상 코드** : `fwu_v2/Logic/Failover.py`  
> **기준 커밋** : `0e0a374d983bf194220e75da79b28598673bc0fa` (`jh`)  
> **행** = 코드 줄 번호 (빈 줄은 생략)  
> **표기** : `→` 들여쓰기 단계 · *[주석]* 코드 안 주석 · **※** 읽을 때 주의할 점

특정 중대 알람을 모아 Failover 알람을 유지하고, 최초 발생 시 운전 OFF를 기록한다.

**목차**

- [1~9행 · 상수 및 적용 범위](#section-1)
- [10~13행 · Failover 원인 집계](#section-2)
- [15~23행 · 최초 발생 시 처리](#section-3)
- [25~36행 · 알람 리셋](#section-4)

**※ 공통 표기**: 알람 1=발생, 0=해제. 조건이 거짓이라고 모든 관제점이 자동으로 0이 되지는 않는다. 해당 분기에 쓰기 명령이 없으면 이전 값이 남는다. `SECTIMER(..., 0)`은 타이머 초기화, `SECTIMER(..., 1)`은 경과시간 확인이다. 명시적 P번호가 없는 쓰기는 `WRITEPOINT` 기본 우선순위를 사용한다.

## 15~23행 · 최초 발생 시 처리

> 원인이 5초 초과 지속되고 아직 알람이 없을 때만 OFF 기록

| 행 | 해석 |
|---:|---|
| 15 | *[주석] 알람 최초 발생 시 P11 OFF를 한 번 기록한다. 지속 정지/재기동 금지는 아니다.* |
| 16 | *[주석] 더 높은 우선순위의 ON이 있으면 이 OFF보다 우선한다.* |
| 17 | Failover 원인 존재 여부 = 1이면 : |
| 18 | &emsp;→&nbsp;Failover 확인 타이머(번호 1) 경과시간이 5초 초과 **그리고** Failover 알람 (`VP_FWU_Failover_Alarm`) = 0이면 : |
| 19 | &emsp;&emsp;→&nbsp;Failover 알람 (`VP_FWU_Failover_Alarm`)에 1 (알람 발생) 기록 — 기본 쓰기 우선순위 |
| 20 | &emsp;&emsp;→&nbsp;FWU 운전 명령 (`VP_FWU_Command`)에 0 (정지) 기록 — P11 |
| 21 | &emsp;&emsp;→&nbsp;HMI 운전 명령 (`VP_FWU_Command-HMI`)에 0 (정지) 기록 — P11 |
| 22 | 17행 조건이 성립하지 않으면 : |
| 23 | &emsp;→&nbsp;Failover 확인 타이머(번호 1)를 0초로 초기화 |

## 25~36행 · 알람 리셋

> 원인이 사라진 상태에서 리셋하면 알람 해제

| 행 | 해석 |
|---:|---|
| 25 | *[주석] 원인이 사라진 뒤 리셋해야 알람이 해제된다.* |
| 26 | *[주석] 5초는 리셋 입력 복귀 시간이며, 알람 해제 대기시간이 아니다.* |
| 27 | *[주석] HMI/BMS가 더 높은 우선순위로 Reset을 쓰면 해당 입력도 해제해야 한다.* |
| 28 | Failover 리셋 입력 (`VP_FWU_Failover_Reset`) = 1이면 : |
| 29 | &emsp;→&nbsp;Failover 원인 존재 여부 = 0이면 : |
| 30 | &emsp;&emsp;→&nbsp;Failover 알람 (`VP_FWU_Failover_Alarm`)에 0 (알람 해제) 기록 — 기본 쓰기 우선순위 |
| 31 | &emsp;→&nbsp;리셋 입력 복귀 타이머(번호 2) 경과시간이 5초 초과하면 : |
| 32 | &emsp;&emsp;→&nbsp;Failover 리셋 입력 (`VP_FWU_Failover_Reset`)에 0 기록 — P11 |
| 33 | &emsp;&emsp;→&nbsp;리셋 입력 복귀 타이머(번호 2)를 0초로 초기화 |
| 34 | 28행 조건이 성립하지 않으면 : |
| 35 | &emsp;→&nbsp;리셋 입력 복귀 타이머(번호 2)를 0초로 초기화 |
| 36 | *[주석] LJH[2026.1117]기존 Failover 원인과 래치 유지: E ----* |

## 읽을 때 짚어둘 점

- **※** 원인이 사라져도 알람이 자동 해제되지 않는다. 리셋이 있어야 해제된다.
- **※** 리셋 부분의 5초는 리셋 입력을 0으로 되돌리는 시간이다. 원인이 없으면 알람 해제는 리셋을 읽은 실행에서 바로 수행한다.
- **※** P11 OFF는 알람 최초 발생 시 한 번 기록한다. 지속 정지 강제나 인접 FWU 가속 명령은 이 코드에 없다.
