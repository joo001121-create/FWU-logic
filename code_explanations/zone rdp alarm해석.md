## 읽을 때 짚어둘 점

- **※** Count는 자동으로 발견한 통신 센서 수가 아니라 설정값이다. 3이면 1~3번을 사용하고 4~10번의 타이머와 알람을 해제한다.
- **※** 고장 판정은 값이 0 이하인지 보는 방식이다. 통신이 끊겼는데 이전의 정상 범위 값이 남아 있는 경우를 이 코드만으로 알 수는 없다.
- **※** 평균·최대·최소 계산은 이 블록에서 하지 않는다. 여기서는 센서별 고장 알람을 만든다.
