## 1~12행 · 머리말, 안내 주석, PI 게인

> 공통 AO 하나로 밸브 4 대에 같은 명령

| 행 | 해석 |
|---:|---|
| 1 | *[주석] LJH 2026-11-17 수정 구간 시작. 주제 = 네 밸브(PICV 4대)에 공통 냉방 명령 하나를 보냄* |
| 2 | 상수: PICV PI 루프 번호 = 1 (LOOP2 / LOOP2_INIT 에서 사용) |
| 3 | *[주석] AO3(`FWU_PICV_CONTROL`) 하나의 공통 명령을 4대 밸브에 같이 보냄. 개도·유량·온도는 밸브마다 RS485 로 받음* |
| 4 | *[주석] 밸브가 유량 모드이면 100 % = "설정 최대 유량을 달라"는 뜻이고, 실제 개도 100 % 와는 다르다* |
| 5 | *[주석] SAT 센서 고장 시 100 % 요구를 유지. 센서 복구 후 PI 누적값 때문에 출력·온도가 흔들리는지 확인 필요* |
| 6 | *[주석] Command=1 인데 팬이 아직 안 돌면 기존 명령을 그대로 둠. 비상(P1)·원격정지(P2)는 따로 우선 적용* |
| 7 | *[주석] 수동 모드에서 Command=0 이어도 밸브가 자동으로 닫히지 않음. 바람 없을 때 냉수가 흐르는 것에 대한 HMI 안내 검토* |
| 8 | *[주석] AO 선이 끊기거나 전원이 나갔을 때 밸브가 어디로 가는지는 제조사 확인 후 대응 여부 결정. 단선 시 0%로 돌아가는 밸브는 사용하지 않아야 함* |
| 9 | DDC 로직 엔진 객체 생성 (이후 engine.xxx 로 관제점 읽기/쓰기) |
| 11 | PICV PI 제어 비례 게인(P) 읽기 (`VP_FWU_PICV_PGain`) |
| 12 | PICV PI 제어 적분 게인(I) 읽기 (`VP_FWU_PICV_IGain`) |

## 14~28행 · 평상시 (자동 / 수동)

> 자동: 팬 운전 중 SAT PI 제어, 정지 명령 시 닫힘, P11 백업 / 수동: P5 해제

| 행 | 해석 |
|---:|---|
| 14 | 비상 DI(`FWU_EMERGENCY`)가 0 이면 (평상시) : |
| 15 | &emsp;→&nbsp;밸브 출력(`FWU_PICV_CONTROL`)의 비상 우선순위 P1 해제 (비상이 풀렸으므로) |
| 16 | &emsp;→&nbsp;운전 모드가 자동(1) 이면 : |
| 17 | &emsp;&emsp;→&nbsp;운전 명령 Command = 1 이고 팬이 돌고 있으면 (SF Status = 1) : |
| 18 | &emsp;&emsp;&emsp;→&nbsp;SAT(급기온도) 센서 고장 알람이 1 이면 |
| 19 | &emsp;&emsp;&emsp;&emsp;→&nbsp;밸브 출력 100 % (P5). 온도를 모르니 최대 냉방 쪽으로 |
| 20 | &emsp;&emsp;&emsp;→&nbsp;SAT 센서 고장 알람이 1이 아니면 : (고장 확정 대기 중인 경우까지 실제 센서 정상이라고 보증하는 조건은 아님) |
| 21 | &emsp;&emsp;&emsp;&emsp;→&nbsp;PI 제어: 방향 1, 급기온도 SAT가 설정값보다 높으면 냉방 요구를 높이는 방향. PV=`FWU_SAT`, 출력=`FWU_PICV_CONTROL`, SP=`VP_FWU_PICV_SAT_SP`, D=0, 샘플링 인수 1, 시작 출력 인수 100, 범위 MinSP~100, 루프 1, 불감대 0. 유량 모드에서는 실제 개도보다 유량 요구로 해석 |
| 22 | &emsp;&emsp;→&nbsp;Command = 0 (정지 명령) 이면 : |
| 23 | &emsp;&emsp;&emsp;→&nbsp;PI 루프 1 누적값 초기화 |
| 24 | &emsp;&emsp;&emsp;→&nbsp;공통 밸브 출력에 0% 요구 기록. 실제로 닫혔는지 확인하는 동작은 아니며, 피드백 확인은 PICV Feedback에서 수행 |
| 25 | &emsp;&emsp;→&nbsp;현재 읽히는 밸브 출력값을 P11에도 복사 (다른 우선순위 명령이 없을 때 수동 전환 후 이 값이 이어지도록)<br>**※** Command=1·팬 정지 상태에서는 위에서 새 출력을 쓰지 않아 기존 명령이 남음 |
| 26 | &emsp;→&nbsp;운전 모드가 자동(1)이 아니면 : |
| 27 | &emsp;&emsp;→&nbsp;PI 루프 1 초기화 |
| 28 | &emsp;&emsp;→&nbsp;자동 쓰기 P5를 해제. P1·P2 등 더 높은 우선순위 명령이 없으면 P11 값이 적용될 수 있음. HMI가 쓴 값이 무조건 출력된다는 뜻은 아님 |

> P1 과 P11 에 0

|---:|---|

| 33 | *[주석] LJH 2026-11-17 수정 구간 끝* |

## 코드와 함께 읽을 때

- **※** SAT 고장 시 100% 요구는 자동·운전 명령 1·팬 운전 상태 1 조건 안에서 수행한다. 모든 상태에서 무조건 100%를 쓰는 것은 아니다.
- **※** 이 코드의 출력은 네 밸브 공통 명령이다. 0% 또는 100% 명령을 썼다는 사실과 실제 밸브 개도·유량이 그 값에 도달했다는 사실은 구분해야 한다.
