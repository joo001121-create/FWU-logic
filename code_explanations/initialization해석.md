## 코드와 함께 읽을 때

- **※** CZT/HZT/RDP 집계의 “정상 센서”는 해당 고장 알람이 0인 센서를 뜻한다. 이 블록은 측정값 범위를 직접 검사하지 않으므로 Zone 알람의 고장 확정 대기 중에는 잘못된 값이 집계에 포함될 수 있다.
- **※** 상위 통신 알람은 Heartbeat가 다시 바뀌었다는 이유만으로 자동 해제되지 않는다. 반면 감시 사용을 끄는 분기에서는 알람을 해제한다.
- **※** CZH는 센서 고장 알람과 상위 통신 상태를 집계 조건으로 확인하지 않는다. Count에 포함된 값으로 평균·최대·최소를 계산한다.
