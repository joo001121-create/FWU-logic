## 2026-11-17 — F8 제어 코드 초안 작성

### 변경 파일·이유

`STATIC_CHECKS.json`의 changed_runtime_files에 실행 관련 15개 파일을 기록했다. 세 주 제어 블록, Alarm-1/2/3의 필요한 연결, Remote Shutdown/Failover의 표기, 보조 블록 5개, VirtualPoint와 DDC 등록이 대상이다. 구체적 변경과 합의 연결은 IMPLEMENTATION.md에 정리했다.

문서 추가: README 개정, IMPLEMENTATION, INTEGRATION, POINTS_ADDED, STATIC_CHECKS, TEST_RESULTS, CHANGES.diff, BASELINE_SHA256, SOURCE_HEADERS, tests/test_control.py. 코드 작성 전 합의 문서는 원본 그대로 보존했다.

### 구현 중 구체화한 사항

- 상위 감시와 외부 센서 개수 기본값은 모두 0으로 두었다. 실장 설정에서 명시적으로 연결한다. 감시 해제 시 알람·이전값·타이머 정리, 재사용 시 기본 유예를 적용했다.
- 센서 타이머 부족은 종류별 보조 블록 3개로 해결했다. 댐퍼와 PICV 수신 감시도 별도 블록이다.
- Belimo 레지스터 미확정으로 실제 CH3 어댑터는 작성하지 않았다. 임시 전달 VP와 수신 번호/품질 계약을 만들고 초기·만료 데이터로 닫힘을 판정하지 않게 했다.
- 명령-개도 편차 검사는 위치 모드에서만 활성화했다. 유량 기준은 확인 후 켜도록 기본 미사용으로 뒀다. 진단 보류를 정상으로 혼동하지 않도록 Monitor Ready를 제공했다.
- 수신 timeout 10초는 기존 유량계 기준에서 가져온 임시값이다. 적용 모드, 진단 enable, 수신 계약은 새로운 HW 확인 전제이며 지원이 입증됐다는 의미가 아니다.
